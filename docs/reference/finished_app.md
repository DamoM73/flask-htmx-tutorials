When it's finished, our ***studym8*** folder will look like this:

```text
studym8/
    .venv/
    static/
        style.css
    templates/
        partials/
            account.html
            add.html
            assessment_card.html
            calendar.html
            edit_form.html
            home.html
            login.html
            register.html
            set_details.html
            welcome.html
        base.html
        fragment.html
        nav.html
    app.py
    assessment_service.py
    db.py
    schema.sql
    studym8.db
    user_service.py
```
